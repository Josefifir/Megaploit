# Megaploit requirements
#
# Two install modes
# -----------------
# Flexible (end-users, development):
#   pip install -r requirements.txt
#
# Reproducible / pinned (CI, staging, deployments):
#   pip install -r requirements.txt -c constraints.txt
#
# Updating pinned versions after changing bounds here:
#   pip install pip-tools
#   pip-compile requirements.in --output-file constraints.txt
#
# System requirements:
#   git must be on PATH (for toolbox clone/update and self-update checks)
#   For exe/elf payload compilation: pip install pyinstaller
#   For UPX packing: install upx from https://upx.github.io/
#
# Optional extras that unlock additional capabilities:
#   pip install cryptography          # AES-256-GCM transport (required for encrypted sessions)
#   pip install flask                 # Web dashboard (web start)
#   pip install impacket              # SMB share enumeration module
#   pip install dnspython             # DNS resolver module (all record types)
#   pip install pyinstaller           # payload exe / payload elf compilation
#   pip install weasyprint            # PDF export from HTML reports
